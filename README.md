# 소정 누나 생일 카드

[카드 열기](https://pollmap.github.io/sojeong-birthday-card-2026/?v=2)

소정 누나에게 보내는 모바일 생일 카드입니다. 초대장을 열면 피카츄와 피츄가 입장하고, 케이크 점등 → 한 박자 어긋난 큰절 → 축하 색종이 → 촛불을 켜 둔 축하 장면으로 이어집니다. 서명은 이찬희 드림입니다.

## 사용과 구성

- `index.html`: 문구, 초대장과 파티 화면, 공유 메타데이터
- `party.css`: 화면 구성, 모바일 안전 영역, 애니메이션과 동작 줄이기 지원
- `card.js`: 약 10초의 연출 순서, 촛불 점등, 선택형 소리, 다시 보기, 링크 복사
- `assets/*-party.svg`, `assets/party-cake.svg`: 이 카드에 맞춰 코드로 그린 벡터 그림
- `og-sojeong-party-v2.png`: 1200×630 공유 썸네일. `og-preview.html`이 원본 구성입니다.

폴더에서 `python -m http.server 4182 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:4182/`를 여세요. 설치할 JS 라이브러리나 외부 API는 없습니다. GitHub Pages는 main 브랜치 루트에서 배포합니다.

소리는 기본으로 꺼져 있으며 사용자가 버튼을 눌렀을 때만 Web Audio를 시작합니다. 마이크 권한은 사용하지 않습니다. 작은 화면과 가로 모드에서는 필요한 만큼 세로 스크롤이 가능합니다. 화면을 벗어나면 진행 중인 연출을 마무리해 돌아왔을 때 효과가 겹치지 않게 합니다. 동작 줄이기 설정에서는 바로 축하 장면을 보여줍니다.

메신저가 이전 썸네일을 캐시할 수 있어 썸네일 파일명을 새로 지정했습니다. 새 공유용 링크에는 `?v=2`가 붙습니다. 실제 카카오톡·iPhone Safari 기기 검증과 브라우저에서의 화면 크기 검증은 서로 다릅니다.

Pokémon 캐릭터를 재해석해 그린 비공식 개인 팬 카드입니다. 관련 캐릭터 권리는 각 권리자에게 있습니다. 이전 버전의 이미지 자산은 이력 보존용이며 새 화면에서는 불러오지 않습니다.
